Two ways to build the same card
From scratch
Six new hex values, a shadow nobody else uses, and a radius that drifts 2px from the scale. Ships fast, ages badly.
From the system
One component, three props. Flat, zero radius, photograph full-bleed. Looks like the rest of the product on day one and on day 400.
How to approach a new screen
Read
Find the closest existing screen and copy its structure before you draw anything.
Compose
Build it from components only. If something is missing, note it — don't improvise a one-off.
Check
Every value traces back to a token. Anything that doesn't is a decision you now own.
