The grid unit of every PLP and product rail: full-bleed square photograph with metadata stacked directly below.

```jsx
<ProductCard name="Trail Runner GTX" category="Men's Trail Running Shoes"
  price="$97.97" wasPrice="$140" discount="30% off"
  badge="Just In" colors={["#111111", "#0a7281", "#f5f5f5"]} />
```

Zero radius, zero shadow, zero internal padding — the photograph is the card. Metadata order is fixed: swatch dots, name, category, colour count, price. Rows sit 8px apart.
