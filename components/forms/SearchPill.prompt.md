The only documented form field in the system — a soft-cloud pill anchored to the right of the primary nav.

```jsx
<SearchPill placeholder="Search" width={240} />
```

Focus swaps the fill to canvas, adds a 2px ink border and a 12px soft-cloud halo (`--focus-ring`) — the system's only focus effect. Radius stays `--radius-search` (24px) so the halo reads as a glove, not an outline.
